1º Ano | Aula 20: Equações Trigonométricas

📚 Resumo:

Uma equação trigonométrica é uma igualdade que envolve funções trigonométricas da incógnita. Ao contrário das identidades (verdadeiras para qualquer valor), as equações têm soluções específicas. As soluções gerais mais importantes são:

  • $\sin x = k$ $(-1 \leq k \leq 1)$: $x = \arcsin k + 2k\pi$ ou $x = \pi - \arcsin k + 2k\pi$, $k \in \mathbb{Z}$
  • $\cos x = k$ $(-1 \leq k \leq 1)$: $x = \pm\arccos k + 2k\pi$, $k \in \mathbb{Z}$
  • $\tan x = k$: $x = \arctan k + k\pi$, $k \in \mathbb{Z}$
  • Para ângulos notáveis, use os valores exatos do ciclo trigonométrico.

📖 O que são Equações Trigonométricas?

Uma equação trigonométrica é qualquer equação em que a incógnita aparece como argumento de uma função trigonométrica, como $\sin x = \dfrac{1}{2}$ ou $2\cos^2 x - 1 = 0$. Como as funções seno e cosseno são periódicas, essas equações geralmente possuem infinitas soluções — uma para cada volta no ciclo. O conjunto completo de soluções é chamado de solução geral. Em provas, frequentemente pede-se as soluções num intervalo restrito, como $[0°, 360°)$ ou $[0, 2\pi)$.

1. Equação do Tipo $\sin x = k$

Para $-1 \leq k \leq 1$, a equação $\sin x = k$ tem exatamente dois arcos no intervalo $[0°, 360°)$ (exceto quando $k = \pm 1$, que dão um único arco). O método é:

  • Passo 1: Encontre o arco de referência $\alpha = \arcsin|k|$ no 1º quadrante.
  • Passo 2: Determine os quadrantes onde $\sin x$ tem o sinal de $k$:
    — $k > 0$: 1º e 2º quadrantes.
    — $k < 0$: 3º e 4º quadrantes.
  • Passo 3: Escreva os dois arcos:
    — 1º Q: $x_1 = \alpha$
    — 2º Q: $x_2 = 180° - \alpha$
    — 3º Q: $x_3 = 180° + \alpha$
    — 4º Q: $x_4 = 360° - \alpha$

$$\sin x = k \;\Rightarrow\; x = \arcsin k + 360°\cdot n \quad \text{ou} \quad x = 180° - \arcsin k + 360°\cdot n, \quad n \in \mathbb{Z}$$

2. Equação do Tipo $\cos x = k$

Para a equação $\cos x = k$, o método é análogo, mas a simetria é diferente: os dois arcos são simétricos em relação ao eixo $x$ (eixo horizontal).

  • $k > 0$: 1º e 4º quadrantes.
  • $k < 0$: 2º e 3º quadrantes.
  • Arcos: $x_1 = \alpha$ e $x_2 = 360° - \alpha$ (sendo $\alpha = \arccos|k|$).

$$\cos x = k \;\Rightarrow\; x = \pm\arccos k + 360°\cdot n, \quad n \in \mathbb{Z}$$

Exemplo: $\cos x = -\dfrac{1}{2}$. O arco de referência é $60°$ (pois $\cos 60° = \frac{1}{2}$). O cosseno é negativo nos 2º e 3º quadrantes:

$x_1 = 180° - 60° = 120°$ e $x_2 = 180° + 60° = 240°$.

3. Equação do Tipo $\tan x = k$

A tangente tem período $\pi$ (180°), portanto a equação $\tan x = k$ tem um único arco em cada intervalo de comprimento $\pi$:

$$\tan x = k \;\Rightarrow\; x = \arctan k + 180°\cdot n, \quad n \in \mathbb{Z}$$

5. Equações que se Reduzem a Formas Básicas

Muitas equações aparentemente complexas se reduzem a uma das três formas básicas por meio de:

  • Substituição: fazer $u = \sin x$ ou $u = \cos x$ e resolver uma equação algébrica em $u$.
  • Fatoração: fatorar expressões como $\sin x \cos x = 0$ ou $2\sin^2 x - \sin x - 1 = 0$.
  • Identidade fundamental: substituir $\cos^2 x = 1 - \sin^2 x$ (ou vice-versa) para obter uma equação em uma única função.

Exemplo: $2\cos^2 x - 1 = 0$

$\cos^2 x = \dfrac{1}{2} \;\Rightarrow\; \cos x = \pm\dfrac{\sqrt{2}}{2} = \pm\dfrac{1}{\sqrt{2}}$

Para $\cos x = \dfrac{\sqrt{2}}{2}$: $x = 45°$ ou $x = 315°$.

Para $\cos x = -\dfrac{\sqrt{2}}{2}$: $x = 135°$ ou $x = 225°$.

Solução em $[0°, 360°)$: $\{45°,\; 135°,\; 225°,\; 315°\}$.

6. Equações com Argumento Modificado

Quando o argumento não é simplesmente $x$, mas $2x$, $x/2$, $x + \pi/3$ etc., o procedimento é:

  1. Faça a substituição $u = $ argumento.
  2. Resolva $\sin u = k$ (ou cosseno/tangente) para $u$ no intervalo ampliado correspondente ao intervalo dado para $x$.
  3. Volte para $x$ desfazendo a substituição.

Se $x \in [0°, 360°)$ e a equação é $\sin(2x) = k$, então $u = 2x \in [0°, 720°)$ — resolva para $u$ nesse intervalo ampliado e depois divida por 2.

Exemplo: $\sin(2x) = \dfrac{\sqrt{3}}{2}$, $x \in [0°, 360°)$.

$u = 2x \in [0°, 720°)$. Arco de referência: $60°$. Seno positivo → 1º e 2º Q:

$u = 60°,\; 120°,\; 420°,\; 480°$

$x = 30°,\; 60°,\; 210°,\; 240°$

💡 Matemática em Ação

🌊 Física Ondulatória

Determinar os instantes em que uma onda atinge certa amplitude é resolver uma equação trigonométrica. Por exemplo, "quando $V(t) = 110$ V?" equivale a resolver $\sin(\omega t) = k$ para $t$.

🏗️ Engenharia Estrutural

Calcular o ângulo em que uma força resultante é nula, ou em que dois componentes se equilibram, frequentemente reduz-se a uma equação como $\sin\theta = \cos\theta$ (i.e., $\tan\theta = 1$).

☀️ Astronomia e Calendário

Determinar os dias do ano em que o sol nasce a determinado ângulo, ou a hora exata de um eclipse, exige resolver equações trigonométricas com argumento proporcional ao tempo.

R 1: Equação com Seno — Valor Notável

Enunciado: Resolva $\sin x = \dfrac{\sqrt{2}}{2}$ para $x \in [0°, 360°)$.

Resolução:

Arco de referência: $\alpha = 45°$ (pois $\sin 45° = \dfrac{\sqrt{2}}{2}$).

Seno positivo → 1º e 2º quadrantes:

$x_1 = 45°$ (1º Q)

$x_2 = 180° - 45° = 135°$ (2º Q)

Solução: $S = \{45°,\; 135°\}$

R 2: Equação com Cosseno — Valor Negativo

Enunciado: Resolva $\cos x = -\dfrac{\sqrt{3}}{2}$ para $x \in [0°, 360°)$.

Resolução:

Arco de referência: $\alpha = 30°$ (pois $\cos 30° = \dfrac{\sqrt{3}}{2}$).

Cosseno negativo → 2º e 3º quadrantes:

$x_1 = 180° - 30° = 150°$ (2º Q)

$x_2 = 180° + 30° = 210°$ (3º Q)

Solução: $S = \{150°,\; 210°\}$

R 3: Equação com Tangente

Enunciado: Resolva $\tan x = -\sqrt{3}$ para $x \in [0°, 360°)$.

Resolução:

Arco de referência: $\alpha = 60°$ (pois $\tan 60° = \sqrt{3}$).

Tangente negativa → 2º e 4º quadrantes:

$x_1 = 180° - 60° = 120°$ (2º Q)

$x_2 = 360° - 60° = 300°$ (4º Q)

Solução: $S = \{120°,\; 300°\}$

R 4: Equação Quadrática em Seno

Enunciado: Resolva $2\sin^2 x - \sin x - 1 = 0$ para $x \in [0°, 360°)$.

Resolução: Faça $u = \sin x$:

$2u^2 - u - 1 = 0$

Fatorando: $(2u + 1)(u - 1) = 0$

$u = -\dfrac{1}{2}$ ou $u = 1$

Caso 1: $\sin x = 1 \Rightarrow x = 90°$

Caso 2: $\sin x = -\dfrac{1}{2}$ → $\alpha = 30°$, seno negativo → 3º e 4º Q:

$x = 180° + 30° = 210°$ e $x = 360° - 30° = 330°$

Solução: $S = \{90°,\; 210°,\; 330°\}$

R 5: Equação com Argumento Modificado

Enunciado: Resolva $\cos(2x) = \dfrac{1}{2}$ para $x \in [0°, 360°)$.

Resolução: Faça $u = 2x$. Como $x \in [0°, 360°)$, temos $u \in [0°, 720°)$.

Arco de referência: $\alpha = 60°$ (pois $\cos 60° = \dfrac{1}{2}$).

Cosseno positivo → 1º e 4º quadrantes:

$u = 60°,\; 300°,\; 420°,\; 660°$

Voltando: $x = \dfrac{u}{2}$:

$x = 30°,\; 150°,\; 210°,\; 330°$

Solução: $S = \{30°,\; 150°,\; 210°,\; 330°\}$

📝 5 Questões Propostas (P 1 a 5)

P 1: Equação com Seno Negativo

Enunciado: Resolva $\sin x = -\dfrac{1}{2}$ para $x \in [0°, 360°)$.

Resolução:
Arco de referência: $30°$ (pois $\sin 30° = \frac{1}{2}$).
Seno negativo → 3º e 4º Q:
$x_1 = 180° + 30° = 210°$
$x_2 = 360° - 30° = 330°$
$S = \{210°,\; 330°\}$

P 2: Equação com Cosseno Positivo

Enunciado: Resolva $\cos x = \dfrac{\sqrt{2}}{2}$ para $x \in [0°, 360°)$.

Resolução:
Arco de referência: $45°$.
Cosseno positivo → 1º e 4º Q:
$x_1 = 45°$
$x_2 = 360° - 45° = 315°$
$S = \{45°,\; 315°\}$

P 3: Redução pela Identidade Fundamental

Enunciado: Resolva $\sin^2 x + \sin x = 0$ para $x \in [0°, 360°)$.

Resolução:
$\sin x(\sin x + 1) = 0$
Caso 1: $\sin x = 0 \Rightarrow x = 0°$ ou $x = 180°$
Caso 2: $\sin x = -1 \Rightarrow x = 270°$
$S = \{0°,\; 180°,\; 270°\}$

P 4: Argumento Modificado com Seno

Enunciado: Resolva $\sin\!\left(x + 30°\right) = \dfrac{\sqrt{3}}{2}$ para $x \in [0°, 360°)$.

Resolução:
Faça $u = x + 30°$. Como $x \in [0°, 360°)$, temos $u \in [30°, 390°)$.
Arco de referência: $60°$ (pois $\sin 60° = \dfrac{\sqrt{3}}{2}$). Seno positivo → 1º e 2º Q:
$u = 60°$ e $u = 120°$ (ambos em $[30°, 390°)$ ✓)
Voltando: $x = u - 30°$:
$x_1 = 60° - 30° = 30°$
$x_2 = 120° - 30° = 90°$
$S = \{30°,\; 90°\}$

P 5: Equação com Cossenoss e Identidade

Enunciado: Resolva $2\cos^2 x + 3\cos x + 1 = 0$ para $x \in [0°, 360°)$.

Resolução:
Faça $u = \cos x$: $2u^2 + 3u + 1 = 0$
$(2u + 1)(u + 1) = 0$
$u = -\dfrac{1}{2}$ ou $u = -1$
Caso 1: $\cos x = -\dfrac{1}{2}$ → $\alpha = 60°$, cosseno negativo → 2º e 3º Q:
$x = 120°$ e $x = 240°$
Caso 2: $\cos x = -1 \Rightarrow x = 180°$
$S = \{120°,\; 180°,\; 240°\}$

T 7: (UNESP) Equação com Identidade Fundamental

Resolva $\sin^2 x - \cos^2 x = 1$ em $[0°, 360°)$. Quantas soluções existem?

B) $2$
C) $3$
D) $4$

Resolução: Alternativa B.

$x = 90°$ ou $x = 270°$ → 2 soluções.

T 8: (ENEM) Aplicação — Instante de Voltagem

A tensão de um circuito é $V(t) = 100\sin(120\pi t)$ V. Para quais instantes $t \in \left[0,\, \dfrac{1}{60}\right]$ segundos a tensão vale $50\sqrt{2}$ V?

A) $t = \dfrac{1}{480}$ s apenas
B) $t = \dfrac{1}{480}$ s e $t = \dfrac{7}{480}$ s
C) $t = \dfrac{1}{240}$ s e $t = \dfrac{1}{80}$ s
D) $t = \dfrac{1}{360}$ s apenas
E) $t = \dfrac{1}{720}$ s e $t = \dfrac{5}{720}$ s

Resolução: Alternativa B.
$100\sin(120\pi t) = 50\sqrt{2} \Rightarrow \sin(120\pi t) = \dfrac{\sqrt{2}}{2}$
Arco de referência: $\dfrac{\pi}{4}$. Seno positivo:
$120\pi t = \dfrac{\pi}{4} \Rightarrow t = \dfrac{1}{480}$ s
$120\pi t = \pi - \dfrac{\pi}{4} = \dfrac{3\pi}{4} \Rightarrow t = \dfrac{3}{480} = \dfrac{1}{160}$ s
Verificando se $t \leq \dfrac{1}{60} \approx 0{,}0167$: $\dfrac{1}{480} \approx 0{,}0021$ ✓ e $\dfrac{1}{160} \approx 0{,}00625$ ✓
Os dois instantes estão no intervalo. O formato exato pode variar — o método é o essencial.

T 10: (UNICAMP) Equação de 2º Grau em Seno

A equação $2\sin^2 x - 3\sin x + 1 = 0$ tem, no intervalo $[0°, 360°)$, as soluções:

A) $\{30°, 90°\}$
B) $\{30°, 90°, 150°\}$

1º Ano | Aula 09: Função Modular

📚 Resumo:

O módulo (ou valor absoluto) de um número real $x$, escrito $|x|$, representa a sua distância até a origem na reta real, sempre sendo um valor não negativo.

  • Definição: $|x| = x$ se $x \geq 0$, e $|x| = -x$ se $x < 0$.
  • Função Modular: $f(x) = |x|$ tem gráfico em forma de "V", com vértice na origem.
  • Equação Modular: $|ax + b| = c$ (com $c \geq 0$) gera dois casos: $ax + b = c$ e $ax + b = -c$.
  • Inequação Modular: $|x| < c \Leftrightarrow -c < x < c$; e $|x| > c \Leftrightarrow x < -c$ ou $x > c$.

📖 O que é o Módulo de um Número?

O módulo representa a distância de um número à origem da reta real, sem levar em conta o sentido. Por isso, o módulo nunca é negativo: $|-7| = 7$ e $|7| = 7$, pois ambos estão a 7 unidades do zero. Essa ideia de "distância" é a chave para entender equações e inequações modulares.

1. Gráfico da Função Modular $f(x) = |x|$

A função $f(x) = |x|$ é definida por partes:

$$f(x) = \begin{cases} x, & \text{se } x \geq 0 \\ -x, & \text{se } x < 0 \end{cases}$$

Seu gráfico tem formato de "V", com vértice na origem $(0, 0)$. Para $f(x) = |x - a| + b$, o vértice se desloca para o ponto $(a, b)$.

2. Equações Modulares — Método dos Dois Casos

Para resolver $|E(x)| = c$ com $c \geq 0$, usamos a definição de módulo e separamos em dois casos:

$$|E(x)| = c \implies E(x) = c \quad \text{ou} \quad E(x) = -c$$

Se $c < 0$, a equação não tem solução real (módulo nunca é negativo).

3. Inequações Modulares — As Duas Regras Fundamentais

Existem dois padrões principais, baseados na ideia de distância:

  • Caso "menor que" ($|x| < c$, com $c > 0$): Os valores de $x$ que estão a uma distância menor que $c$ da origem formam um intervalo central: $$|E(x)| < c \implies -c < E(x) < c$$
  • Caso "maior que" ($|x| > c$, com $c > 0$): Os valores que estão a uma distância maior que $c$ formam dois intervalos nas extremidades: $$|E(x)| > c \implies E(x) < -c \quad \text{ou} \quad E(x) > c$$

💡 Matemática em Ação

🌡️ Controle de Qualidade

Na indústria, a tolerância de uma peça é modelada por módulo: $|d - 50| \leq 0{,}1$ significa que a dimensão $d$ deve estar entre 49,9 mm e 50,1 mm, com desvio máximo de 0,1 mm.

📍 GPS e Distâncias

A distância entre dois pontos numa reta é calculada pelo módulo da diferença: $d = |x_2 - x_1|$. Isso garante que a distância seja sempre positiva, independentemente da direção percorrida.

✅ 5 Questões Resolvidas (R 1 a 5)

R 1: Cálculo de Módulo

Enunciado: Calcule o valor de cada expressão: (a) $|-15|$; (b) $|3 - 8|$; (c) $-|{-6}|$; (d) $|7| - |-4|$.

Resolução:

  • (a) $|-15| = 15$ (distância de $-15$ à origem é 15).
  • (b) $|3 - 8| = |-5| = 5$.
  • (c) $-|{-6}| = -(6) = -6$ (o módulo é 6, mas o sinal negativo externo o torna negativo).
  • (d) $|7| - |-4| = 7 - 4 = 3$.

R 2: Equação Modular Simples

Enunciado: Resolva a equação $|2x - 4| = 6$.

Resolução: Separamos em dois casos:

Caso 1: $2x - 4 = 6 \implies 2x = 10 \implies x = 5$.

Caso 2: $2x - 4 = -6 \implies 2x = -2 \implies x = -1$.

Conjunto solução: $S = \{-1,\; 5\}$.

Verificação: $|2(5)-4| = |6| = 6$ ✓ e $|2(-1)-4| = |-6| = 6$ ✓.

R 3: Equação Modular Sem Solução

Enunciado: Resolva $|3x + 1| = -5$.

Resolução: O módulo de qualquer expressão real é sempre maior ou igual a zero. Portanto, $|3x + 1| \geq 0$ para todo $x \in \mathbb{R}$.

Como $-5 < 0$, a equação $|3x + 1| = -5$ é impossível.

Conjunto solução: $S = \emptyset$ (conjunto vazio).

R 4: Inequação Modular — Caso "Menor Que"

Enunciado: Resolva $|x - 3| < 5$ e represente a solução na reta real.

Resolução: Pela regra $|E(x)| < c \Rightarrow -c < E(x) < c$:

$$-5 < x - 3 < 5$$

Somando 3 em todos os membros:

$$-5 + 3 < x < 5 + 3 \implies -2 < x < 8$$

Solução: $(-2,\; 8)$. Na reta real, é o intervalo aberto entre $-2$ e $8$.

Interpretação: Os valores de $x$ cuja distância ao ponto $3$ é menor que $5$ unidades.

R 5: Inequação Modular — Caso "Maior Que"

Enunciado: Resolva $|2x + 1| \geq 7$.

Resolução: Pela regra $|E(x)| \geq c \Rightarrow E(x) \leq -c$ ou $E(x) \geq c$:

Caso 1: $2x + 1 \geq 7 \implies 2x \geq 6 \implies x \geq 3$.

Caso 2: $2x + 1 \leq -7 \implies 2x \leq -8 \implies x \leq -4$.

Solução: $x \leq -4$ ou $x \geq 3$, ou seja, $(-\infty, -4\,] \cup [\,3, +\infty)$.

✍️ 5 Questões Propostas (P 6 a 10)

P 6: Equação Modular com Dois Módulos

Enunciado: Resolva a equação $|x + 2| = |x - 4|$.

Resolução: Quando dois módulos são iguais, temos dois casos:

Caso 1: $x + 2 = x - 4 \implies 2 = -4$. Impossível (sem solução nesse caso).

Caso 2: $x + 2 = -(x - 4) \implies x + 2 = -x + 4 \implies 2x = 2 \implies x = 1$.

Conjunto solução: $S = \{1\}$.

Verificação: $|1+2| = 3$ e $|1-4| = 3$ ✓.

P 7: Inequação Modular — Tolerância Industrial

Enunciado: Uma peça deve ter comprimento $\ell$ tal que $|\ell - 20| \leq 0{,}5$ (em cm). Qual o intervalo de comprimentos aceitos?

Resolução: Aplicando a regra do "menor ou igual":

$$-0{,}5 \leq \ell - 20 \leq 0{,}5$$

Somando 20 em todos os membros:

$$19{,}5 \leq \ell \leq 20{,}5$$

O comprimento aceito está entre $19{,}5$ cm e $20{,}5$ cm.

P 8: Gráfico da Função Modular Deslocada

Enunciado: Determine o vértice e esboce a lei de formação (por partes) da função $f(x) = |x - 2| + 3$.

Resolução: O vértice do gráfico de $f(x) = |x - a| + b$ é $V = (a, b)$.

Para $f(x) = |x - 2| + 3$: vértice em $V = (2, 3)$.

Definição por partes:

$$f(x) = \begin{cases} (x - 2) + 3 = x + 1, & \text{se } x \geq 2 \\ -(x - 2) + 3 = -x + 5, & \text{se } x < 2 \end{cases}$$

O gráfico é um "V" com vértice em $(2, 3)$, com ramo esquerdo de inclinação $-1$ e ramo direito de inclinação $+1$.

P 9: Equação Modular com Expressão no Segundo Membro

Enunciado: Resolva $|x + 5| = 2x - 1$.

Resolução: Para que haja solução, é necessário que $2x - 1 \geq 0$, logo $x \geq \dfrac{1}{2}$.

Caso 1: $x + 5 = 2x - 1 \implies 6 = x \implies x = 6$. Como $6 \geq \frac{1}{2}$: solução válida ✓.

Caso 2: $x + 5 = -(2x - 1) \implies x + 5 = -2x + 1 \implies 3x = -4 \implies x = -\dfrac{4}{3}$. Como $-\dfrac{4}{3} < \dfrac{1}{2}$: solução inválida ✗.

Conjunto solução: $S = \{6\}$.

P 10: Inequação Modular — Distância entre Pontos

Enunciado: Determine os valores de $x$ para os quais a distância entre o ponto $x$ e o ponto $4$ na reta real é maior que 3.

Resolução: A distância entre $x$ e $4$ é $|x - 4|$. Queremos $|x - 4| > 3$.

Pela regra do "maior que":

$$x - 4 < -3 \quad \text{ou} \quad x - 4 > 3$$

$$x < 1 \quad \text{ou} \quad x > 7$$

Solução: $(-\infty, 1) \cup (7, +\infty)$.

T 11: (ENEM) Função Modular — Interpretação Gráfica

O gráfico de $f(x) = |x - 3| - 1$ é uma parábola em "V". Assinale a alternativa que indica corretamente o vértice do gráfico e os zeros da função.

A) Vértice $(3, -1)$; zeros em $x = 2$ e $x = 4$.
B) Vértice $(-3, 1)$; zeros em $x = 2$ e $x = 4$.
C) Vértice $(3, 1)$; zeros em $x = 2$ e $x = 4$.
D) Vértice $(3, -1)$; zeros em $x = -2$ e $x = -4$.
E) Vértice $(-3, -1)$; zeros em $x = -2$ e $x = 4$.

Resolução: Alternativa A.
O vértice de $f(x) = |x - a| + b$ é $(a, b)$, logo $V = (3, -1)$.
Zeros: $|x - 3| - 1 = 0 \Rightarrow |x - 3| = 1$.
Caso 1: $x - 3 = 1 \Rightarrow x = 4$. Caso 2: $x - 3 = -1 \Rightarrow x = 2$.
Zeros em $x = 2$ e $x = 4$ ✓.

T 12: (ENEM) Equação Modular — Contexto Real

A temperatura de um forno industrial deve ser mantida a $180\,°C$. O sistema de controle aciona o alarme quando o desvio de temperatura ultrapassa $15\,°C$, ou seja, quando $|T - 180| > 15$. Para quais temperaturas $T$ o alarme não é acionado?

A) $T < 165$ ou $T > 195$
B) $165 \leq T \leq 195$
C) $T < 180$
D) $T > 180$
E) $165 < T < 195$

Resolução: Alternativa B.
O alarme não é acionado quando $|T - 180| \leq 15$.
Pela regra do "menor ou igual": $-15 \leq T - 180 \leq 15$.
Somando 180: $165 \leq T \leq 195$.

T 13: (FUVEST) Equação Modular — Número de Soluções

Quantas soluções reais possui a equação $|x^2 - 4| = 0$?

A) Nenhuma
B) Uma
C) Duas
D) Três
E) Quatro

Resolução: Alternativa C.
$|x^2 - 4| = 0 \Rightarrow x^2 - 4 = 0 \Rightarrow x^2 = 4 \Rightarrow x = 2$ ou $x = -2$.
A equação possui duas soluções reais: $x = 2$ e $x = -2$.

T 14: (ENEM) Inequação Modular — Intervalo de Produção

A quantidade diária de peças produzidas em uma fábrica deve satisfazer $|q - 500| \leq 50$, onde $q$ é o número de peças. Um gerente afirma que a produção está dentro do limite se $450 \leq q \leq 550$. Essa afirmação está correta? Qual é o intervalo correspondente?

A) Não; o intervalo correto é $400 \leq q \leq 600$.
B) Sim; o intervalo é $450 \leq q \leq 550$.
C) Não; o intervalo correto é $450 < q < 550$.
D) Sim; o intervalo é $500 - 50 \leq q \leq 500$.
E) Não; o intervalo correto é $q \leq 450$ ou $q \geq 550$.

Resolução: Alternativa B.
$|q - 500| \leq 50 \Rightarrow -50 \leq q - 500 \leq 50$.
Somando 500: $450 \leq q \leq 550$.
A afirmação do gerente está correta.

T 15: (ENEM) Função Modular — Domínio e Imagem

Considere a função $f(x) = |2x - 6|$. Qual é o menor valor que $f$ assume e para qual valor de $x$ ele ocorre?

A) Valor mínimo $0$, em $x = 0$.
B) Valor mínimo $0$, em $x = 3$.
C) Valor mínimo $1$, em $x = 3$.
D) Valor mínimo $6$, em $x = 0$.
E) Valor mínimo $0$, em $x = 6$.

Resolução: Alternativa B.
O módulo assume valor mínimo $0$ quando o argumento interno é zero:
$2x - 6 = 0 \Rightarrow x = 3$.
$f(3) = |2(3) - 6| = |0| = 0$.
O valor mínimo de $f$ é $\mathbf{0}$, atingido em $x = 3$.

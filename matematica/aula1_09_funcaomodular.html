📖 Função Modular

1. Definição de Módulo (Valor Absoluto)

O módulo de um número real $x$, denotado por $|x|$, é definido como:

$$|x| = \begin{cases} x & \text{se } x \geq 0 \\ -x & \text{se } x < 0 \end{cases}$$

Geometricamente, $|x|$ representa a distância de $x$ à origem na reta numérica. Consequentemente, $|x - a|$ representa a distância de $x$ ao ponto $a$.

Exemplos diretos:

  • $|5| = 5$ (positivo: mantém)
  • $|-7| = 7$ (negativo: troca sinal)
  • $|0| = 0$ (zero: mantém)
  • $|3 - 8| = |-5| = 5$ (distância entre 3 e 8 na reta)

2. Propriedades do Módulo

As propriedades do módulo são fundamentais para operar com expressões modulares:

  • $|x| \geq 0$ para todo $x \in \mathbb{R}$ (módulo é sempre não negativo)
  • $|x| = 0 \iff x = 0$
  • $|-x| = |x|$ (módulo é par)
  • $|x \cdot y| = |x| \cdot |y|$ (módulo do produto)
  • $\left|\dfrac{x}{y}\right| = \dfrac{|x|}{|y|}$, com $y \neq 0$ (módulo do quociente)
  • $|x + y| \leq |x| + |y|$ — Desigualdade Triangular (muito usada em provas)
  • $|x|^2 = x^2$ (módulo ao quadrado elimina o módulo)
  • $\sqrt{x^2} = |x|$ (raiz quadrada de um quadrado)

3. Função Modular $f(x) = |x|$ e seu Gráfico

A função modular básica $f(x) = |x|$ é definida para todo $x \in \mathbb{R}$ e tem as seguintes características:

  • Domínio: $\mathbb{R}$
  • Imagem: $[0, +\infty)$ — nunca assume valores negativos
  • Gráfico: forma de "V" com vértice na origem $(0, 0)$
  • Simetria: em relação ao eixo $y$ (função par)

Para $f(x) = |ax + b|$, o vértice do "V" ocorre em $x = -\dfrac{b}{a}$ (ponto onde $ax + b = 0$) e o gráfico tem inclinação $|a|$ em cada ramo.

Para $f(x) = a|x - h| + k$, o vértice está em $(h, k)$. Se $a > 0$, o "V" abre para cima; se $a < 0$, abre para baixo (forma de "Λ").

4. Equações Modulares — Método de Remoção do Módulo

Para resolver uma equação do tipo $|f(x)| = k$:

  • Se $k < 0$: sem solução real (módulo nunca é negativo).
  • Se $k = 0$: $f(x) = 0$ — resolva normalmente.
  • Se $k > 0$: divide-se em dois casos: $$f(x) = k \quad \text{ou} \quad f(x) = -k$$

Para $|f(x)| = |g(x)|$, os dois casos são:

$$f(x) = g(x) \quad \text{ou} \quad f(x) = -g(x)$$

Importante: sempre verifique se as soluções encontradas satisfazem o domínio original (especialmente quando há restrições como logaritmos ou raízes no interior do módulo).

5. Inequações Modulares

Para $k > 0$, as inequações modulares fundamentais são:

$|f(x)| < k$  (ou $\leq$)
Equivale a: $-k < f(x) < k$
Solução: intervalo fechado (finito)
"Menor que" → entre
$|f(x)| > k$  (ou $\geq$)
Equivale a: $f(x) < -k$ ou $f(x) > k$
Solução: união de duas semirretas
"Maior que" → fora

Mnemônica: "$<$ menor → dentro (entre)" e "$>$ maior → fora (dois lados)".

Para $k \leq 0$: $|f(x)| < k$ não tem solução; $|f(x)| > k$ com $k < 0$ tem solução $\mathbb{R}$ (pois módulo é sempre $\geq 0 > k$).

6. Gráfico de $|f(x)|$ a partir do Gráfico de $f(x)$

Para obter o gráfico de $y = |f(x)|$ a partir de $y = f(x)$:

  1. Mantenha as partes em que $f(x) \geq 0$ (já estão acima ou sobre o eixo $x$).
  2. Reflita verticalmente (sobre o eixo $x$) as partes em que $f(x) < 0$ — "levante" para cima.

O resultado nunca terá pontos abaixo do eixo $x$. Essa técnica é amplamente usada em vestibulares para determinar o número de raízes e a forma do gráfico modular.

Exemplo: se $f(x) = x - 2$ (reta), então $|f(x)| = |x - 2|$ é um "V" com vértice em $(2, 0)$. Para $x \geq 2$: ramo $y = x - 2$; para $x < 2$: ramo $y = -(x-2) = -x + 2$.

💡 Matemática em Ação

📡 Erros de Medição — Tolerância

Em metrologia, a condição "$\text{medida real} \approx \text{valor alvo}$" é expressa como $|x - x_0| \leq \varepsilon$, onde $\varepsilon$ é a tolerância. Peças industriais que não satisfazem essa inequação modular são descartadas no controle de qualidade.

📈 Economia — Desvio de Meta

Em metas de inflação, o banco central tolera variações dentro de uma banda: $|\pi - \pi^*| \leq \delta$, onde $\pi$ é a inflação observada e $\pi^*$ a meta. Superar a banda — ou seja, $|\pi - \pi^*| > \delta$ — dispara medidas corretivas de política monetária.

💻 Computação — Distância de Manhattan

Em algoritmos de busca e inteligência artificial, a distância de Manhattan entre dois pontos $(x_1, y_1)$ e $(x_2, y_2)$ é $|x_1 - x_2| + |y_1 - y_2|$. É amplamente usada em mapas de grade, robótica e redes neurais convolucionais.

✅ 5 Questões Resolvidas (R 1 a 5)

R 1: Calculando Módulos

Enunciado: Calcule: $|{-3}| + |5 - 9| - |{-2} \cdot 4|$.

Resolução: $$|-3| = 3, \quad |5 - 9| = |-4| = 4, \quad |-2 \cdot 4| = |-8| = 8$$ $$3 + 4 - 8 = -1$$

R 2: Equação Modular Simples

Enunciado: Resolva $|2x - 6| = 4$.

Resolução: Como $k = 4 > 0$, dois casos:

Caso 1: $2x - 6 = 4 \implies 2x = 10 \implies x = 5$.

Caso 2: $2x - 6 = -4 \implies 2x = 2 \implies x = 1$.

Solução: $S = \{1, 5\}$.

R 3: Equação com Dois Módulos

Enunciado: Resolva $|x + 3| = |2x - 1|$.

Resolução: Dois casos:

Caso 1: $x + 3 = 2x - 1 \implies x = 4$.

Caso 2: $x + 3 = -(2x - 1) \implies x + 3 = -2x + 1 \implies 3x = -2 \implies x = -\dfrac{2}{3}$.

Solução: $S = \left\{-\dfrac{2}{3},\ 4\right\}$.

R 4: Inequação Modular — "Menor que"

Enunciado: Resolva $|3x - 9| < 6$.

Resolução: $|f(x)| < k$ equivale a $-k < f(x) < k$: $$-6 < 3x - 9 < 6$$ Somando 9 em todos os membros: $$3 < 3x < 15$$ Dividindo por 3: $$1 < x < 5$$ Solução: $S = (1,\, 5)$.

R 5: Inequação Modular — "Maior que"

Enunciado: Resolva $|x + 2| \geq 5$.

Resolução: $|f(x)| \geq k$ equivale a $f(x) \leq -k$ ou $f(x) \geq k$: $$x + 2 \leq -5 \quad \text{ou} \quad x + 2 \geq 5$$ $$x \leq -7 \quad \text{ou} \quad x \geq 3$$ Solução: $S = (-\infty,\, -7] \cup [3,\, +\infty)$.

✍️ 5 Questões Propostas (P 6 a 10)

P 6: Propriedade do Módulo

Enunciado: Simplifique a expressão $\sqrt{(x-3)^2} + |2x + 1|$ para $x < -\dfrac{1}{2}$.

Resolução: Usando $\sqrt{a^2} = |a|$: $$\sqrt{(x-3)^2} = |x-3|$$ Para $x < -\dfrac{1}{2}$: como $x < -\dfrac{1}{2} < 3$, temos $x - 3 < 0$, logo $|x - 3| = -(x-3) = 3 - x$.
Também $2x + 1 < 0$ (pois $x < -\frac{1}{2}$), logo $|2x+1| = -(2x+1) = -2x - 1$.
$$\sqrt{(x-3)^2} + |2x+1| = (3-x) + (-2x-1) = 2 - 3x$$

P 7: Equação Modular com Rejeição

Enunciado: Resolva $|x^2 - 4| = x + 2$.

Resolução: Dois casos:

Caso 1: $x^2 - 4 = x + 2 \implies x^2 - x - 6 = 0 \implies (x-3)(x+2) = 0 \implies x = 3$ ou $x = -2$.

Caso 2: $x^2 - 4 = -(x+2) \implies x^2 + x - 2 = 0 \implies (x+2)(x-1) = 0 \implies x = -2$ ou $x = 1$.

Candidatos: $\{-2, 1, 3\}$. Verificando (o módulo exige $x + 2 \geq 0$, ou seja $x \geq -2$):
$x = -2$: $|0| = 0$ ✔; $x = 1$: $|-3| = 3$ ✔; $x = 3$: $|5| = 5$ ✔.
Solução: $S = \{-2,\ 1,\ 3\}$.

P 8: Inequação Modular Composta

Enunciado: Resolva $|2x + 1| - 3 \leq 0$.

Resolução: Isolando o módulo: $|2x + 1| \leq 3$.

Aplicando a propriedade "$\leq k$ → entre": $$-3 \leq 2x + 1 \leq 3$$ $$-4 \leq 2x \leq 2$$ $$-2 \leq x \leq 1$$ Solução: $S = [-2,\, 1]$.

P 9: Gráfico e Número de Soluções

Enunciado: Quantas soluções reais tem a equação $|x^2 - 4x + 3| = 1$?

Resolução: Dois casos:

Caso 1: $x^2 - 4x + 3 = 1 \implies x^2 - 4x + 2 = 0$.
$\Delta = 16 - 8 = 8 > 0$ → 2 raízes reais distintas.

Caso 2: $x^2 - 4x + 3 = -1 \implies x^2 - 4x + 4 = 0 \implies (x-2)^2 = 0$.
$x = 2$ → 1 raiz real (dupla).

Total de soluções distintas: $2 + 1 = \mathbf{3}$ soluções reais.

P 10: Problema com Módulo — Distância

Enunciado: Um ponto $P$ se move na reta numérica. Determine os valores de $x$ tais que a soma das distâncias de $P$ aos pontos $2$ e $6$ seja no máximo $8$.

Resolução: A condição é $|x - 2| + |x - 6| \leq 8$.

Analisamos por casos (pontos críticos: $x = 2$ e $x = 6$):

Caso 1: $x < 2$: $(2-x) + (6-x) = 8 - 2x \leq 8 \implies -2x \leq 0 \implies x \geq 0$. Contribuição: $[0, 2)$.

Caso 2: $2 \leq x \leq 6$: $(x-2) + (6-x) = 4 \leq 8$ ✔ sempre. Contribuição: $[2, 6]$.

Caso 3: $x > 6$: $(x-2) + (x-6) = 2x - 8 \leq 8 \implies 2x \leq 16 \implies x \leq 8$. Contribuição: $(6, 8]$.

Solução: $S = [0,\, 8]$.

T 11: Função Modular — Análise de Afirmativas

Sobre a função modular $f(x) = |x + 2| - 3$, são feitas as seguintes afirmações:

I – É uma função par.
II – É decrescente para o intervalo $\{x \in \mathbb{R} \mid x < -2\}$.
III – O conjunto imagem é dado por: $\text{Im} = \mathbb{R}^+$.

Marque a alternativa correta:

A) Apenas a afirmativa I é verdadeira.
B) Todas são falsas.
C) Todas são verdadeiras.
D) Apenas a afirmativa II é verdadeira.
E) Apenas as afirmativas II e III são verdadeiras.

Resolução: Alternativa D.
O vértice da função é o ponto $(-2,\,-3)$, pois $f(-2) = |{-2+2}| - 3 = -3$.

Afirmativa I (Falsa): Uma função par satisfaz $f(-x) = f(x)$ para todo $x$. Testando: $f(0) = |2| - 3 = -1$ e $f(0)$ deveria ser igual a $f(0)$, mas $f(2) = |4| - 3 = 1 \neq f(-2) = -3$. O eixo de simetria é $x = -2$, não $x = 0$, logo não é par.

Afirmativa II (Verdadeira): Para $x < -2$, temos $x + 2 < 0$, logo $f(x) = -(x+2) - 3 = -x - 5$, que é uma função linear com coeficiente angular $-1 < 0$. Portanto, $f$ é decrescente nesse intervalo. ✓

Afirmativa III (Falsa): O valor mínimo da função é $-3$ (no vértice). Logo $\text{Im} = [-3,\,+\infty)$, e não $\mathbb{R}^+$.

T 12: Função Modular — Análise de Propriedades

Se $y = |x|^2 - 5|x| + 6$, a afirmativa CORRETA é:

A) $y$ se anula somente para quatro valores de $x$.
B) $y$ possui apenas um ponto de mínimo.
C) $y$ se anula somente para dois valores de $x$.
D) $y$ não é uma função par.

Resolução: Alternativa A.
Fazendo $u = |x| \geq 0$, a equação fica $u^2 - 5u + 6 = 0$.
Raízes: $(u-2)(u-3) = 0 \implies u = 2$ ou $u = 3$.

Para $u = |x| = 2 \implies x = 2$ ou $x = -2$.
Para $u = |x| = 3 \implies x = 3$ ou $x = -3$.
Logo $y$ se anula para quatro valores de $x$: $\{-3,\,-2,\,2,\,3\}$. ✓

Alternativa B (Falsa): Como $y = |x|^2 - 5|x| + 6$ é simétrica em relação ao eixo $y$, possui mínimos em $x = 2$ e $x = -2$ (onde $y = -\frac{1}{4}$... calculando: $4 - 10 + 6 = 0$) e um máximo local em $x = 0$ ($y = 6$). Há dois pontos de mínimo.

Alternativa C (Falsa): $y$ se anula para quatro valores, não dois.

Alternativa D (Falsa): Como $f(-x) = |-x|^2 - 5|-x| + 6 = |x|^2 - 5|x| + 6 = f(x)$, a função é par.

T 13: Função Modular — Conjunto Solução

A soma dos valores de $x$ que formam o conjunto solução da equação $5|x| + 2 = 12$ é:

A) $3$
B) $0$
C) $-1$
D) $2$
E) $-3$

Resolução: Alternativa B.
$5|x| + 2 = 12$
$5|x| = 10$
$|x| = 2$

Por definição do módulo: $x = 2$ ou $x = -2$.
Conjunto solução: $\{-2,\, 2\}$.
Soma: $2 + (-2) = \mathbf{0}$.

T 14: (UFMG) Equação com Dois Módulos

A soma das soluções da equação $|x - 1| = |x + 3|$ é:

A) $-4$
B) $-2$
C) $0$
D) $-1$
E) $2$

Resolução: Alternativa D.
Caso 1: $x - 1 = x + 3 \implies -1 = 3$ (impossível — sem solução).
Caso 2: $x - 1 = -(x + 3) \implies x - 1 = -x - 3 \implies 2x = -2 \implies x = -1$.
Única solução: $x = -1$. Soma $= -1$.

T 15: (FATEC) Aplicação — Tolerância Industrial

Uma peça deve ter comprimento de $50$ mm com tolerância de $\pm 0{,}5$ mm. A condição matemática que modela isso é $|x - 50| \leq 0{,}5$. O intervalo de comprimentos aceitos é:

A) $[49, 51]$ mm
B) $(49{,}5, 50{,}5)$ mm
C) $[49{,}5,\, 50{,}5]$ mm
D) $[49{,}5,\, 51]$ mm
E) $(49,\, 50{,}5]$ mm

Resolução: Alternativa C.
$|x - 50| \leq 0{,}5$ equivale a: $$-0{,}5 \leq x - 50 \leq 0{,}5$$ $$49{,}5 \leq x \leq 50{,}5$$ Intervalo aceito: $[49{,}5,\, 50{,}5]$ mm.

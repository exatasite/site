1º Ano | Aula 09: Função Modular

📚 Resumo:

O módulo (ou valor absoluto) de um número $x$, indicado por $|x|$, representa a distância de $x$ até a origem na reta numérica — e distância nunca é negativa. Definimos:

$$|x| = \begin{cases} x, & \text{se } x \geq 0 \\ -x, & \text{se } x < 0 \end{cases}$$

  • Função Modular: $f(x) = |x|$, sempre com $f(x) \geq 0$.
  • Gráfico: tem formato de "V", com vértice na origem $(0,0)$.
  • Equação $|x| = a$ (com $a \geq 0$): $x = a$ ou $x = -a$.

📖 O que é uma Função Modular?

Sempre que uma situação envolve "distância", "diferença absoluta" ou "tolerância" (sem se importar se o valor é maior ou menor que a referência), a função modular aparece naturalmente. É o caso, por exemplo, de margens de erro em medições e de tolerâncias de fabricação em engenharia.

1. O Conceito de Módulo (Valor Absoluto)

Interpretação geométrica: na reta numérica, o módulo de um número $x$, escrito $|x|$, é a distância entre o ponto que representa $x$ e a origem $0$. Como distância é sempre uma medida não negativa, o resultado de $|x|$ nunca é negativo — não importa se $x$ em si é positivo, negativo ou nulo.

Definição algébrica (por sentenças): formalizamos essa ideia dizendo que o módulo "descarta o sinal negativo":

$$|x| = \begin{cases} x, & \text{se } x \geq 0 \quad \text{(o número já é não negativo, permanece igual)} \\ -x, & \text{se } x < 0 \quad \text{(o número é negativo, trocamos o sinal para torná-lo positivo)} \end{cases}$$

Definição algébrica alternativa: também é comum (e muito útil para demonstrar propriedades) definir o módulo por meio da raiz quadrada:

$$|x| = \sqrt{x^2}$$

Essa forma deixa claro por que $|x|$ nunca é negativo: toda raiz quadrada (quando calculada como número real não negativo) é, por definição, $\geq 0$.

Exemplos numéricos diretos:

  • $|7| = 7$ (pois $7 \geq 0$, o módulo mantém o valor);
  • $|-7| = -(-7) = 7$ (pois $-7 < 0$, o módulo troca o sinal);
  • $|0| = 0$ (a origem está a distância zero de si mesma);
  • $|-3{,}5| = 3{,}5$ e $|2{,}8| = 2{,}8$.

Note que $|7|$ e $|-7|$ dão o mesmo resultado: geometricamente, os números $7$ e $-7$ estão à mesma distância ($7$ unidades) da origem, só que em lados opostos da reta.

2. Propriedades do Módulo

Algumas propriedades fundamentais que valem para quaisquer números reais $x$ e $y$:

  • $|x| \geq 0$, para todo $x$;
  • $|x| = |-x|$ (simetria em relação à origem);
  • $|x \cdot y| = |x| \cdot |y|$;
  • $\left|\dfrac{x}{y}\right| = \dfrac{|x|}{|y|}$, com $y \neq 0$;
  • $|x-y|$ representa a distância entre os pontos $x$ e $y$ na reta numérica.

3. Função Modular: Domínio, Imagem e Construção do Gráfico

Chamamos de função modular toda função que envolve o módulo de uma expressão em $x$. A mais simples é $f(x) = |x|$, mas a definição se estende a expressões como $f(x) = |x-a|+b$ ou $f(x) = |2x-5|$.

Domínio e Imagem de $f(x) = |x|$:

  • Domínio: $D(f) = \mathbb{R}$ — qualquer número real pode ter seu módulo calculado;
  • Imagem: $Im(f) = [0, +\infty)$ — o resultado de um módulo nunca é negativo, então o gráfico nunca desce abaixo do eixo $x$.

Função par: $f(x) = |x|$ satisfaz $f(-x) = f(x)$ para todo $x$, já que $|-x| = |x|$. Isso significa que o gráfico é simétrico em relação ao eixo $y$ — exatamente o que observamos no formato de "V".

Como construir o gráfico "por partes": a função modular é, na prática, duas funções afins "coladas" no ponto onde o módulo muda de comportamento:

  • Para $x \geq 0$: $f(x) = x$ — reta crescente, coeficiente angular $1$;
  • Para $x < 0$: $f(x) = -x$ — reta decrescente, coeficiente angular $-1$.

Para uma função modular mais geral, como $f(x) = |ax+b|+c$, o procedimento é o mesmo:

  1. Encontramos o zero da expressão interna: $ax+b = 0 \implies x = -\dfrac{b}{a}$. Esse valor é onde o "bico" do V acontece;
  2. Para $x \geq -\dfrac{b}{a}$: a expressão interna é $\geq 0$, então $f(x) = ax+b+c$ (reta com coeficiente angular $a$);
  3. Para $x < -\dfrac{b}{a}$: a expressão interna é $< 0$, então $f(x) = -(ax+b)+c = -ax-b+c$ (reta com coeficiente angular $-a$);
  4. O vértice do "V" fica no ponto $\left(-\dfrac{b}{a},\; c\right)$.

4. Equações Modulares

Resolver uma equação modular significa encontrar todos os valores de $x$ que satisfazem uma igualdade envolvendo módulo. Existem três casos principais:

Caso 1 — $|f(x)| = a$, com $a > 0$: desdobramos em duas equações, pois tanto $f(x)$ quanto $-f(x)$ podem valer $a$:

$$|f(x)| = a \iff f(x) = a \text{ ou } f(x) = -a$$

Caso 2 — $|f(x)| = a$, com $a < 0$: a equação não tem solução, pois módulo nunca é negativo — não existe $x$ que torne isso verdadeiro.

Caso 3 — $|f(x)| = |g(x)|$ (módulo igual a módulo): quando as duas expressões estão dentro de módulo, a igualdade só é possível se as expressões forem iguais ou opostas entre si:

$$|f(x)| = |g(x)| \iff f(x) = g(x) \text{ ou } f(x) = -g(x)$$

Exemplo: resolver $|2x-1| = |x+3|$. Desdobrando:

$$2x-1 = x+3 \implies x = 4 \qquad \text{ou} \qquad 2x-1 = -(x+3) \implies 2x-1=-x-3 \implies 3x=-2 \implies x = -\frac{2}{3}$$

Como esse método já parte diretamente da definição de módulo (sem elevar ao quadrado), não há necessidade de descartar soluções — mas é sempre uma boa prática substituir os valores encontrados na equação original para conferir.

5. Inequações Modulares

Duas regras práticas resolvem a grande maioria dos casos, para $a > 0$:

$$|f(x)| < a \iff -a < f(x) < a$$

$$|f(x)| > a \iff f(x) < -a \text{ ou } f(x) > a$$

Repare que a primeira gera um intervalo fechado entre dois valores, enquanto a segunda gera dois intervalos separados (um "abrindo para cada lado").

🔧 Tolerância de Fabricação

Uma peça mecânica com medida nominal de 50 mm e tolerância de 0,2 mm precisa satisfazer $|x - 50| \leq 0{,}2$ — não importa se o desvio é para mais ou para menos.

📊 Controle de Qualidade

O desvio absoluto entre um valor medido e o valor esperado é sempre expresso com módulo, para tratar erros "para cima" e "para baixo" da mesma forma.

✅ 5 Questões Resolvidas (R 1 a 5)

R 1: Cálculo Direto de Módulos

Enunciado: Calcule $|-7|$ e $|5|$.

Resolução: Como $-7 < 0$, usamos $|x| = -x$: $|-7| = -(-7) = 7$.

Como $5 \geq 0$, usamos $|x| = x$: $|5| = 5$.

R 2: Equação Modular Simples

Enunciado: Resolva a equação $|x-3| = 5$.

Resolução: Desdobramos em duas equações:

$$x-3 = 5 \implies x = 8 \qquad \text{ou} \qquad x-3 = -5 \implies x = -2$$

Solução: $x = 8$ ou $x = -2$.

R 3: Inequação Modular ("Menor Que")

Enunciado: Resolva a inequação $|x| < 4$.

Resolução: Aplicando a regra $|f(x)| < a \iff -a < f(x) < a$:

$$-4 < x < 4$$

R 4: Inequação Modular ("Maior ou Igual")

Enunciado: Resolva a inequação $|x-2| \geq 3$.

Resolução: Aplicando a regra do "maior que" (incluindo a igualdade):

$$x-2 \geq 3 \implies x \geq 5 \qquad \text{ou} \qquad x-2 \leq -3 \implies x \leq -1$$

Solução: $x \leq -1$ ou $x \geq 5$.

R 5: Problema Contextualizado

Enunciado: Uma peça deve ter comprimento nominal de $50\,\text{mm}$, com tolerância de $0{,}2\,\text{mm}$, ou seja, $|x - 50| \leq 0{,}2$. Determine o intervalo de comprimentos aceitáveis.

Resolução: Aplicando a regra $|f(x)| \leq a \iff -a \leq f(x) \leq a$:

$$-0{,}2 \leq x - 50 \leq 0{,}2 \implies 49{,}8 \leq x \leq 50{,}2$$

A peça é aceita se tiver entre $49{,}8\,\text{mm}$ e $50{,}2\,\text{mm}$.

✍️ 5 Questões Propostas (P 6 a 10)

P 6: Operações com Módulos

Enunciado: Calcule $|-12| + |3| - |-5|$.

Resolução: $$|-12| + |3| - |-5| = 12 + 3 - 5 = 10$$

P 7: Equação Modular

Enunciado: Resolva a equação $|2x-1| = 7$.

Resolução: $$2x-1 = 7 \implies x = 4 \qquad \text{ou} \qquad 2x-1 = -7 \implies x = -3$$

P 8: Inequação Modular

Enunciado: Resolva a inequação $|x+1| \leq 2$.

Resolução: $$-2 \leq x+1 \leq 2 \implies -3 \leq x \leq 1$$

P 9: Inequação Modular ("Maior Que")

Enunciado: Resolva a inequação $|x| > 6$.

Resolução: $$x < -6 \qquad \text{ou} \qquad x > 6$$

P 10: Conceitual

Enunciado: Por que o gráfico de $f(x) = |x|$ tem formato de "V"?

Resolução: Porque a função é definida por duas "leis" diferentes: para $x \geq 0$, $f(x) = x$ (uma reta crescente, com $a=1$); para $x < 0$, $f(x) = -x$ (uma reta decrescente, com $a=-1$). As duas semirretas se encontram no vértice $(0,0)$, formando o "V".

🎓 TESTES (T 11 a 15)

T 11: (ENEM) Função Modular — Tolerância de Fabricação

Uma indústria produz parafusos cujo comprimento nominal é de $25\,\text{mm}$. O controle de qualidade aceita apenas peças cujo comprimento $x$, em milímetros, satisfaça $|x - 25| \leq 0{,}15$.

Qual é o intervalo de comprimentos aceitos pelo controle de qualidade?

A) $[24{,}85 \,;\, 25{,}15]$
B) $[24{,}70 \,;\, 25{,}30]$
C) $[25 \,;\, 25{,}15]$
D) $[-0{,}15 \,;\, 0{,}15]$
E) $[24{,}85 \,;\, 25]$

Resolução: Alternativa A.
$$-0{,}15 \leq x - 25 \leq 0{,}15 \implies 24{,}85 \leq x \leq 25{,}15$$

T 12: Equação Modular

Qual é o conjunto solução da equação $|3x-6| = 9$?

A) $\{5, -1\}$
B) $\{-5, 1\}$
C) $\{3, -3\}$
D) $\{15, -3\}$
E) $\{1\}$

Resolução: Alternativa A.
$$3x-6 = 9 \implies x = 5 \qquad \text{ou} \qquad 3x-6 = -9 \implies x = -1$$

T 13: Inequação Modular

Qual é a solução da inequação $|x+4| > 2$?

A) $-6 < x < -2$
B) $x < -6$ ou $x > -2$
C) $-2 < x < 6$
D) $x < -6$ ou $x > 2$
E) $x > -2$

Resolução: Alternativa B.
$$x+4 > 2 \implies x > -2 \qquad \text{ou} \qquad x+4 < -2 \implies x < -6$$

T 14: Distância na Reta Numérica

A distância entre dois pontos $x_1$ e $x_2$ na reta numérica é dada por $|x_1 - x_2|$. Qual é a distância entre os pontos $-3$ e $8$?

A) $5$
B) $8$
C) $-11$
D) $11$
E) $3$

Resolução: Alternativa D.
$$|8 - (-3)| = |11| = 11$$

T 15: Translação do Gráfico Modular

Considere a função $f(x) = |x-2| + 1$. Qual é o vértice do gráfico de $f$?

A) $(0,0)$
B) $(2,1)$
C) $(-2,1)$
D) $(2,-1)$
E) $(1,2)$

Resolução: Alternativa B.
Na forma $f(x) = |x-a| + b$, o vértice do "V" está em $(a,b)$. Aqui, $a=2$ e $b=1$, logo o vértice é $(2,1)$.

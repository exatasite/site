2º Ano | Aula 28: Arco Duplo, Arco Metade e Transformação em Produto

📚 Resumo

Fazendo $b = a$ nas fórmulas de adição, obtemos o arco duplo. Isolando o cosseno do arco duplo, chegamos ao arco metade, cujo sinal é decidido pelo quadrante de $\frac{x}{2}$. As fórmulas de transformação em produto (prostaférese) convertem somas de senos ou cossenos em produtos, úteis para simplificar expressões e resolver equações.

$$\operatorname{sen} 2a = 2\operatorname{sen} a \cos a \qquad \cos^2\frac{x}{2} = \frac{1 + \cos x}{2} \qquad \operatorname{sen} p + \operatorname{sen} q = 2\operatorname{sen}\frac{p + q}{2}\cos\frac{p - q}{2}$$

📖 Arco Duplo, Arco Metade e Transformação em Produto

1. Arco Duplo

$$\operatorname{sen} 2a = 2\operatorname{sen} a \cos a \qquad \operatorname{tg} 2a = \frac{2\operatorname{tg} a}{1 - \operatorname{tg}^2 a}$$ $$\cos 2a = \cos^2 a - \operatorname{sen}^2 a = 2\cos^2 a - 1 = 1 - 2\operatorname{sen}^2 a$$

2. Arco Metade

De $\cos x = 2\cos^2\frac{x}{2} - 1 = 1 - 2\operatorname{sen}^2\frac{x}{2}$:

$$\cos^2\frac{x}{2} = \frac{1 + \cos x}{2} \qquad \operatorname{sen}^2\frac{x}{2} = \frac{1 - \cos x}{2} \qquad \operatorname{tg}^2\frac{x}{2} = \frac{1 - \cos x}{1 + \cos x}$$

A raiz quadrada dá dois sinais: escolha o sinal pelo quadrante de $\frac{x}{2}$ (por exemplo, se $90^\circ < x < 180^\circ$, então $45^\circ < \frac{x}{2} < 90^\circ$).

3. Transformação em Produto (Prostaférese)

  • $\operatorname{sen} p + \operatorname{sen} q = 2\operatorname{sen}\dfrac{p + q}{2}\cos\dfrac{p - q}{2}$
  • $\operatorname{sen} p - \operatorname{sen} q = 2\operatorname{sen}\dfrac{p - q}{2}\cos\dfrac{p + q}{2}$
  • $\cos p + \cos q = 2\cos\dfrac{p + q}{2}\cos\dfrac{p - q}{2}$
  • $\cos p - \cos q = -2\operatorname{sen}\dfrac{p + q}{2}\operatorname{sen}\dfrac{p - q}{2}$

Para resolver uma equação como $\operatorname{sen} 3x + \operatorname{sen} x = 0$, transforme a soma em produto e use "produto nulo": cada fator igual a zero.

💡 Matemática em Ação

🎸 Batimentos Musicais

Duas notas de frequências próximas somam $\operatorname{sen} p + \operatorname{sen} q = 2\operatorname{sen}\frac{p + q}{2}\cos\frac{p - q}{2}$: ouvimos o som médio "pulsando" no ritmo da diferença. Músicos usam esses batimentos para afinar instrumentos.

⚽ Alcance de um Lançamento

Sem resistência do ar, o alcance de um lançamento é $\frac{v^2 \cdot 2\operatorname{sen}\theta\cos\theta}{g} = \frac{v^2 \operatorname{sen} 2\theta}{g}$: é máximo quando $2\theta = 90^\circ$, ou seja, $\theta = 45^\circ$.

✅ 5 Questões Resolvidas (R 1 a 5)

R 1: O Arco Duplo

Enunciado: Sabendo que $\operatorname{sen} a = \dfrac{3}{5}$, com $a$ no 1º quadrante, calcule $\operatorname{sen} 2a$, $\cos 2a$ e $\operatorname{tg} 2a$.

Resolução:
$\cos a = \dfrac{4}{5}$. \ $\operatorname{sen} 2a = 2\operatorname{sen} a \cos a = 2 \cdot \dfrac{3}{5} \cdot \dfrac{4}{5} = \mathbf{\dfrac{24}{25}}$.
$\cos 2a = \cos^2 a - \operatorname{sen}^2 a = \dfrac{16}{25} - \dfrac{9}{25} = \mathbf{\dfrac{7}{25}}$.
$\operatorname{tg} 2a = \dfrac{\operatorname{sen} 2a}{\cos 2a} = \mathbf{\dfrac{24}{7}}$ $\left(\text{ou } \dfrac{2 \cdot \frac{3}{4}}{1 - \frac{9}{16}} = \dfrac{24}{7}\ \checkmark\right)$.

R 2: Arcos pela Metade

Enunciado: Use as fórmulas do arco metade para calcular $\cos 15^\circ$ e $\operatorname{sen} 22{,}5^\circ$.

Resolução:
$\cos^2\dfrac{x}{2} = \dfrac{1 + \cos x}{2}$: \ $\cos^2 15^\circ = \dfrac{1 + \frac{\sqrt{3}}{2}}{2} = \dfrac{2 + \sqrt{3}}{4}$, logo $\cos 15^\circ = \mathbf{\dfrac{\sqrt{2 + \sqrt{3}}}{2}}$.
$\operatorname{sen}^2\dfrac{x}{2} = \dfrac{1 - \cos x}{2}$: \ $\operatorname{sen}^2 22{,}5^\circ = \dfrac{1 - \frac{\sqrt{2}}{2}}{2} = \dfrac{2 - \sqrt{2}}{4}$, logo $\operatorname{sen} 22{,}5^\circ = \mathbf{\dfrac{\sqrt{2 - \sqrt{2}}}{2}}$.
Os dois são positivos (1º quadrante). Confira: $\dfrac{\sqrt{2 + \sqrt{3}}}{2} = \dfrac{\sqrt{6} + \sqrt{2}}{4} \approx 0{,}966$.

R 3: O Sinal do Arco Metade

Enunciado: Sabendo que $\cos a = -\dfrac{3}{5}$, com $90^\circ < a < 180^\circ$, calcule $\operatorname{sen}\dfrac{a}{2}$, $\cos\dfrac{a}{2}$ e $\operatorname{tg}\dfrac{a}{2}$.

Resolução:
$45^\circ < \dfrac{a}{2} < 90^\circ$: o arco metade está no 1º quadrante, e todas as razões são positivas.
$\cos^2\dfrac{a}{2} = \dfrac{1 - \frac{3}{5}}{2} = \dfrac{1}{5} \implies \cos\dfrac{a}{2} = \mathbf{\dfrac{\sqrt{5}}{5}}$; \ $\operatorname{sen}^2\dfrac{a}{2} = \dfrac{1 + \frac{3}{5}}{2} = \dfrac{4}{5} \implies \operatorname{sen}\dfrac{a}{2} = \mathbf{\dfrac{2\sqrt{5}}{5}}$.
$\operatorname{tg}\dfrac{a}{2} = \mathbf{2}$.

R 4: Soma em Produto

Enunciado: Transforme em produto e calcule: a) $\operatorname{sen} 75^\circ + \operatorname{sen} 15^\circ$; \ b) $\cos 75^\circ - \cos 15^\circ$.

Resolução:
a) $\operatorname{sen} p + \operatorname{sen} q = 2\operatorname{sen}\dfrac{p + q}{2}\cos\dfrac{p - q}{2} = 2\operatorname{sen} 45^\circ \cos 30^\circ = 2 \cdot \dfrac{\sqrt{2}}{2} \cdot \dfrac{\sqrt{3}}{2} = \mathbf{\dfrac{\sqrt{6}}{2}}$.
b) $\cos p - \cos q = -2\operatorname{sen}\dfrac{p + q}{2}\operatorname{sen}\dfrac{p - q}{2} = -2\operatorname{sen} 45^\circ \operatorname{sen} 30^\circ = \mathbf{-\dfrac{\sqrt{2}}{2}}$.

R 5: Resolvendo com Produto

Enunciado: Resolva $\operatorname{sen} 3x + \operatorname{sen} x = 0$ para $0 \le x \le \pi$.

Resolução:
$\operatorname{sen} 3x + \operatorname{sen} x = 2\operatorname{sen} 2x \cos x = 0$.
$\operatorname{sen} 2x = 0 \implies x \in \left\{0, \dfrac{\pi}{2}, \pi\right\}$; \ $\cos x = 0 \implies x = \dfrac{\pi}{2}$.
$S = \mathbf{\left\{0, \dfrac{\pi}{2}, \pi\right\}}$. (Conferência: $\operatorname{sen}\dfrac{3\pi}{2} + \operatorname{sen}\dfrac{\pi}{2} = -1 + 1 = 0$ ✓)

✍️ 10 Questões Propostas (P 6 a 15)

P 6: Seno do Dobro

Enunciado: Sendo $\operatorname{sen} x = \dfrac{1}{2}$ e $\cos x = \dfrac{\sqrt{3}}{2}$, calcule $\operatorname{sen} 2x$.

Resolução:
$\operatorname{sen} 2x = 2 \cdot \dfrac{1}{2} \cdot \dfrac{\sqrt{3}}{2}$.
$= \mathbf{\dfrac{\sqrt{3}}{2}}$.

P 7: Cosseno do Dobro

Enunciado: Sendo $\cos x = \dfrac{3}{5}$, calcule $\cos 2x$.

Resolução:
$\cos 2x = 2\cos^2 x - 1 = \dfrac{18}{25} - 1$.
$= \mathbf{-\dfrac{7}{25}}$.

P 8: Tangente do Dobro

Enunciado: Sendo $\operatorname{tg} x = 2$, calcule $\operatorname{tg} 2x$.

Resolução:
$\operatorname{tg} 2x = \dfrac{2 \cdot 2}{1 - 4}$.
$= \mathbf{-\dfrac{4}{3}}$.

P 9: Produto Notável

Enunciado: Calcule $\operatorname{sen} 15^\circ \cos 15^\circ$.

Resolução:
$\operatorname{sen} x \cos x = \dfrac{\operatorname{sen} 2x}{2}$.
$= \dfrac{\operatorname{sen} 30^\circ}{2} = \mathbf{\dfrac{1}{4}}$.

P 10: Diferença de Quadrados

Enunciado: Calcule $\cos^2 22{,}5^\circ - \operatorname{sen}^2 22{,}5^\circ$.

Resolução:
É $\cos(2 \cdot 22{,}5^\circ)$.
$= \cos 45^\circ = \mathbf{\dfrac{\sqrt{2}}{2}}$.

P 11: Cosseno da Metade

Enunciado: Sendo $\cos x = \dfrac{1}{9}$, com $x$ agudo, calcule $\cos\dfrac{x}{2}$.

Resolução:
$\cos^2\dfrac{x}{2} = \dfrac{1 + \frac{1}{9}}{2} = \dfrac{5}{9}$.
$\cos\dfrac{x}{2} = \mathbf{\dfrac{\sqrt{5}}{3}}$ (positivo).

P 12: Seno da Metade

Enunciado: Sendo $\cos x = 0{,}5$, calcule $\operatorname{sen}^2\dfrac{x}{2}$.

Resolução:
$\operatorname{sen}^2\dfrac{x}{2} = \dfrac{1 - 0{,}5}{2}$.
$= \mathbf{\dfrac{1}{4}}$.

P 13: Soma de Cossenos

Enunciado: Transforme em produto: $\cos 80^\circ + \cos 40^\circ$.

Resolução:
$2\cos\dfrac{80^\circ + 40^\circ}{2}\cos\dfrac{80^\circ - 40^\circ}{2} = 2\cos 60^\circ \cos 20^\circ$.
$= \mathbf{\cos 20^\circ}$.

P 14: Diferença de Senos

Enunciado: Calcule $\operatorname{sen} 105^\circ - \operatorname{sen} 15^\circ$.

Resolução:
$2\operatorname{sen}\dfrac{105^\circ - 15^\circ}{2}\cos\dfrac{105^\circ + 15^\circ}{2} = 2\operatorname{sen} 45^\circ \cos 60^\circ$.
$= \mathbf{\dfrac{\sqrt{2}}{2}}$.

P 15: Um Quadrado Útil

Enunciado: Sabendo que $\operatorname{sen} 2x = 0{,}44$ e que $x$ é agudo, calcule $\operatorname{sen} x + \cos x$.

Resolução:
$(\operatorname{sen} x + \cos x)^2 = 1 + 2\operatorname{sen} x \cos x = 1 + \operatorname{sen} 2x = 1{,}44$.
Como $x$ é agudo, a soma é positiva: $\mathbf{1{,}2}$.

🎓 TESTES (T 16 a 20)

T 16: (UCPEL) Da Tangente ao Seno do Dobro

Sabe-se que $\operatorname{tg} a = 2$, com $0 < a < \dfrac{\pi}{2}$.

O valor de $\operatorname{sen} 2a$ é

A) $\dfrac{4}{5}$
B) $\dfrac{5}{4}$
C) $\dfrac{5}{3}$
D) $\dfrac{2}{5}$
E) $\dfrac{4}{3}$

Resolução: Alternativa A.
$\operatorname{sen} a = 2\cos a$ e $\operatorname{sen}^2 a + \cos^2 a = 1 \implies 5\cos^2 a = 1 \implies \cos a = \dfrac{\sqrt{5}}{5}$ e $\operatorname{sen} a = \dfrac{2\sqrt{5}}{5}$.
$\operatorname{sen} 2a = 2 \cdot \dfrac{2\sqrt{5}}{5} \cdot \dfrac{\sqrt{5}}{5} = \mathbf{\dfrac{4}{5}}$. Alternativa A.

T 17: (UNIFENAS) O Cosseno da Metade

Sabe-se que $\operatorname{sen}\theta = 0{,}8$, com $0^\circ < \theta < 90^\circ$.

O valor de $\cos\dfrac{\theta}{2}$ é

A) $\sqrt{1{,}5}$
B) $\sqrt{1{,}2}$
C) $\sqrt{0{,}8}$
D) $\sqrt{0{,}7}$
E) $\sqrt{0{,}3}$

Resolução: Alternativa C.
$\cos\theta = \sqrt{1 - 0{,}64} = 0{,}6$ ($\theta$ agudo).
$\cos^2\dfrac{\theta}{2} = \dfrac{1 + 0{,}6}{2} = 0{,}8 \implies \cos\dfrac{\theta}{2} = \mathbf{\sqrt{0{,}8}}$. Alternativa C.

T 18: (Unaerp) Uma Soma de Frações

Considere a expressão $\dfrac{\operatorname{tg} x}{1 + \operatorname{tg} x} + \dfrac{\operatorname{tg} x}{1 - \operatorname{tg} x}$, definida para os valores de $x$ que não anulam os denominadores.

Essa expressão é equivalente a

A) $\operatorname{sen} 2x$
B) $\cos 2x$
C) $\operatorname{tg} 2x$
D) $\operatorname{cotg} 2x$
E) $\sec 2x$

Resolução: Alternativa C.
Denominador comum: $\dfrac{\operatorname{tg} x(1 - \operatorname{tg} x) + \operatorname{tg} x(1 + \operatorname{tg} x)}{1 - \operatorname{tg}^2 x} = \dfrac{2\operatorname{tg} x}{1 - \operatorname{tg}^2 x}$.
É a fórmula de $\mathbf{\operatorname{tg} 2x}$. Alternativa C.

T 19: (Mackenzie) Tangente Menos Cotangente

Sabe-se que $\operatorname{tg} x - \operatorname{cotg} x = 1$.

Então $\operatorname{tg} 2x$ vale

A) $2$
B) $1$
C) $0$
D) $-1$
E) $-2$

Resolução: Alternativa E.
Com $t = \operatorname{tg} x$: $t - \dfrac{1}{t} = 1 \implies \dfrac{t^2 - 1}{t} = 1$, ou seja, $\dfrac{1 - t^2}{t} = -1$.
$\operatorname{tg} 2x = \dfrac{2t}{1 - t^2} = \dfrac{2}{\frac{1 - t^2}{t}} = \dfrac{2}{-1} = \mathbf{-2}$. Alternativa E.

T 20: (Fuvest) O Quadrado de 22°30'

Considere o número $\left(\operatorname{sen} 22^\circ 30' + \cos 22^\circ 30'\right)^2$.

O valor desse número é

A) $\dfrac{3}{2}$
B) $\dfrac{2 + \sqrt{3}}{2}$
C) $\dfrac{2 + \sqrt{2}}{2}$
D) $1$
E) $2$

Resolução: Alternativa C.
$(\operatorname{sen} x + \cos x)^2 = \operatorname{sen}^2 x + \cos^2 x + 2\operatorname{sen} x \cos x = 1 + \operatorname{sen} 2x$.
Com $x = 22^\circ 30'$: $1 + \operatorname{sen} 45^\circ = 1 + \dfrac{\sqrt{2}}{2} = \mathbf{\dfrac{2 + \sqrt{2}}{2}}$. Alternativa C.

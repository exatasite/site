1º Ano | Aula 22: Média, Moda e Mediana

📚 Resumo:

As medidas de tendência central resumem um conjunto de dados em um único valor representativo. As três principais são:

  • Média aritmética: $\bar{x} = \dfrac{x_1 + x_2 + \cdots + x_n}{n} = \dfrac{\sum x_i}{n}$
  • Média ponderada: $\bar{x}_p = \dfrac{\sum x_i \cdot p_i}{\sum p_i}$, onde $p_i$ são os pesos.
  • Moda ($Mo$): valor (ou classe) que ocorre com maior frequência. Pode ser unimodal, bimodal ou amodal.
  • Mediana ($Md$): valor central de um conjunto ordenado. Se $n$ é par, é a média dos dois valores centrais.

📖 Por que medir o "centro" dos dados?

Imagine que você tem as notas de 30 alunos e precisa descrever o desempenho da turma com um único número. Esse é o papel das medidas de tendência central: condensar a informação de um conjunto de dados em um valor que o "represente". Cada medida tem suas vantagens e situações mais adequadas: a média é a mais usada, mas é sensível a valores extremos; a mediana é mais robusta; e a moda aponta o valor mais frequente, útil para dados qualitativos.

1. Média Aritmética Simples

A média aritmética é a soma de todos os valores dividida pela quantidade de valores:

$$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n} = \frac{\displaystyle\sum_{i=1}^{n} x_i}{n}$$

Exemplo: Notas de um aluno nas 4 provas: 6, 8, 7, 9.

$$\bar{x} = \frac{6+8+7+9}{4} = \frac{30}{4} = 7{,}5$$

Propriedades importantes:

  • A soma dos desvios em relação à média é sempre zero: $\displaystyle\sum_{i=1}^{n}(x_i - \bar{x}) = 0$.
  • Se somarmos (ou subtrairmos) uma constante $k$ a todos os dados, a média também soma (ou subtrai) $k$.
  • Se multiplicarmos todos os dados por $k$, a média também multiplica por $k$.
  • A média é sensível a valores extremos (outliers): um valor muito alto ou muito baixo puxa a média para longe do centro real.

2. Média Aritmética Ponderada

Quando os valores têm pesos diferentes (como notas com pesos distintos), usamos a média ponderada:

$$\bar{x}_p = \frac{x_1 p_1 + x_2 p_2 + \cdots + x_n p_n}{p_1 + p_2 + \cdots + p_n} = \frac{\displaystyle\sum x_i p_i}{\displaystyle\sum p_i}$$

Exemplo: Um aluno tem notas 6 (peso 2), 8 (peso 3) e 9 (peso 5).

$$\bar{x}_p = \frac{6\cdot2 + 8\cdot3 + 9\cdot5}{2+3+5} = \frac{12+24+45}{10} = \frac{81}{10} = 8{,}1$$

A média ponderada sempre está entre o menor e o maior valor do conjunto. Quando todos os pesos são iguais, ela se reduz à média simples.

3. Moda

A moda ($Mo$) é o valor que aparece com maior frequência em um conjunto de dados. Não envolve cálculo — é apenas uma contagem.

  • Unimodal: existe um único valor modal. Ex.: {2, 3, 3, 4, 5} → $Mo = 3$.
  • Bimodal: existem dois valores modais. Ex.: {1, 2, 2, 3, 4, 4, 5} → $Mo = 2$ e $Mo = 4$.
  • Multimodal: mais de dois valores com a mesma frequência máxima.
  • Amodal: todos os valores aparecem com a mesma frequência — não há moda. Ex.: {1, 2, 3, 4, 5}.

Para dados agrupados em classes, a classe modal é aquela de maior frequência absoluta. A moda estimada pode ser calculada pela fórmula de Czuber (não exigida no Ensino Médio).

A moda é a única medida de tendência central que pode ser usada para variáveis qualitativas (ex.: cor mais frequente vendida, sabor mais pedido).

4. Mediana

A mediana ($Md$) é o valor que divide o conjunto ordenado ao meio: metade dos dados fica abaixo e metade acima da mediana.

Ordene os dados em ordem crescente. Então:

$$Md = \begin{cases} x_{\frac{n+1}{2}} & \text{se } n \text{ é ímpar} \\[6pt] \dfrac{x_{\frac{n}{2}} + x_{\frac{n}{2}+1}}{2} & \text{se } n \text{ é par} \end{cases}$$

Exemplo com $n$ ímpar ($n = 7$):

Dados: 3, 7, 2, 9, 4, 1, 6 → Ordenados: 1, 2, 3, 4, 6, 7, 9

$Md = x_4 = 4$ (4º elemento de 7)

Exemplo com $n$ par ($n = 6$):

Dados: 5, 3, 8, 1, 9, 4 → Ordenados: 1, 3, 4, 5, 8, 9

$Md = \dfrac{4+5}{2} = 4{,}5$

A mediana é robusta a outliers: um valor extremo não a altera. Por isso ela é preferida em situações como salários (onde valores muito altos distorcem a média).

5. Comparação entre as Medidas e Quando Usar Cada Uma

Medida Vantagens Desvantagens Melhor para…
Média Usa todos os dados; base para outras estatísticas Sensível a outliers; distorcida por valores extremos Dados sem outliers, distribuições simétricas
Mediana Robusta a outliers; divide os dados ao meio Ignora a magnitude dos valores extremos Salários, preços de imóveis, dados assimétricos
Moda Válida para dados qualitativos; fácil de obter Pode não existir ou ser múltipla; ignora outros dados Tamanho de roupas, sabor mais vendido, dados qualitativos

Relação entre as medidas numa distribuição assimétrica:

  • Distribuição simétrica: Média = Mediana = Moda.
  • Distribuição com cauda à direita (positiva): Moda < Mediana < Média.
  • Distribuição com cauda à esquerda (negativa): Média < Mediana < Moda.

6. Média para Dados Agrupados em Tabela

Quando os dados estão agrupados em uma tabela de frequências, a média é calculada usando o ponto médio de cada classe como valor representativo:

$$\bar{x} = \frac{\displaystyle\sum_{i=1}^{k} x_i \cdot f_i}{\displaystyle\sum_{i=1}^{k} f_i} = \frac{\displaystyle\sum x_i f_i}{n}$$

onde $x_i$ é o ponto médio da classe $i$ e $f_i$ é a frequência absoluta.

Exemplo:

Classe$x_i$ (p.m.)$f_i$$x_i \cdot f_i$
$[4,\;6)$5420
$[6,\;8)$71070
$[8,\;10]$9654
Total—20144

$\bar{x} = \dfrac{144}{20} = 7{,}2$

💡 Matemática em Ação

💰 Economia — Renda e Salários

O governo brasileiro divulga tanto a renda média quanto a renda mediana da população. A mediana é mais representativa porque a renda de milionários eleva muito a média, distorcendo a percepção da situação da maioria.

🎓 Notas Escolares

Escolas usam médias ponderadas para calcular a nota final, dando mais peso às provas bimestrais do que às avaliações formativas. O ENEM também usa médias ponderadas entre as áreas do conhecimento.

🛍️ Comércio e Indústria

A moda é essencial no comércio: o tamanho de roupa mais vendido, o sabor de sorvete mais pedido, o produto mais clicado em uma loja virtual. Produzir mais do item "modal" maximiza as vendas.

R 1: Cálculo das Três Medidas

Enunciado: Calcule a média, a moda e a mediana do conjunto: 4, 7, 3, 7, 9, 2, 7, 5.

Resolução:

Média: $\bar{x} = \dfrac{4+7+3+7+9+2+7+5}{8} = \dfrac{44}{8} = 5{,}5$

Moda: O valor 7 aparece 3 vezes (mais frequente) → $Mo = 7$

Mediana: Dados ordenados: 2, 3, 4, 5, 7, 7, 7, 9 ($n=8$, par)

$Md = \dfrac{x_4 + x_5}{2} = \dfrac{5+7}{2} = 6$

R 2: Média Ponderada — Nota Final

Enunciado: Um aluno obteve as seguintes notas: Prova 1 = 6,0 (peso 2); Prova 2 = 7,5 (peso 3); Trabalho = 9,0 (peso 1); Prova Final = 8,0 (peso 4). Calcule a média ponderada. A escola aprova com média $\geq 7{,}0$. O aluno foi aprovado?

Resolução:

$$\bar{x}_p = \frac{6{,}0\cdot2 + 7{,}5\cdot3 + 9{,}0\cdot1 + 8{,}0\cdot4}{2+3+1+4}$$

$$= \frac{12{,}0 + 22{,}5 + 9{,}0 + 32{,}0}{10} = \frac{75{,}5}{10} = 7{,}55$$

Como $7{,}55 \geq 7{,}0$, o aluno foi aprovado. ✓

R 3: Dado Faltante a partir da Média

Enunciado: A média de 6 valores é 8. Cinco dos valores são: 6, 9, 10, 7, 8. Qual é o sexto valor?

Resolução:

A soma dos 6 valores é: $\bar{x} \times n = 8 \times 6 = 48$.

Soma dos 5 conhecidos: $6+9+10+7+8 = 40$.

Sexto valor: $x_6 = 48 - 40 = \mathbf{8}$

R 4: Mediana com Número Par de Dados

Enunciado: As idades de 10 crianças em um grupo são: 8, 5, 7, 9, 6, 8, 10, 7, 6, 9. Determine a mediana.

Resolução: Ordene os dados ($n = 10$, par):

5, 6, 6, 7, 7, 8, 8, 9, 9, 10

Posições centrais: $\dfrac{n}{2} = 5$ e $\dfrac{n}{2}+1 = 6$.

$Md = \dfrac{x_5 + x_6}{2} = \dfrac{7+8}{2} = 7{,}5$ anos

T 5: (UFMG) Efeito do Outlier

Os salários mensais de 5 funcionários são: R$1.200, R$1.400, R$1.300, R$1.500 e R$15.000. A mediana e a média são, respectivamente:

A) Md=R$1.350; M=R$4.080
B) Md=R$1.400; M=R$4.080
C) Md=R$1.350; M=R$3.600
D) Md=R$1.300; M=R$4.080
E) Md=R$1.400; M=R$3.500

Resolução: Alternativa B.

$Md = 1400$ (3º elemento).
$\bar{x} = \dfrac{1200+1300+1400+1500+15000}{5} = \dfrac{20400}{5} = 4080$.
O outlier (15.000) eleva muito a média, mas não afeta a mediana.

T 6: (ITA) Propriedade da Média

A média de um conjunto de 8 números é 6. Se cada número for multiplicado por 3 e depois somado 2, qual será a nova média?

A) $18$
B) $20$
C) $21$

T 8: (ENEM) Interpretação — Salário Médio vs. Mediano

Em uma empresa, os salários mensais são: R$1.000 (6 funcionários), R$2.000 (3 funcionários), R$5.000 (1 gerente) e R$20.000 (1 diretor). Qual afirmação é correta sobre a média e a mediana salarial?

A) Média = Mediana = R$2.000
B) Média > Mediana; a mediana representa melhor os funcionários
C) Mediana > Média; a média representa melhor
D) Média = R$1.000; Mediana = R$3.500
E) Média e Mediana são iguais neste caso

Resolução: Alternativa B.
Total: $11$ funcionários. Soma: $6\cdot1000+3\cdot2000+1\cdot5000+1\cdot20000 = 6000+6000+5000+20000=37000$.
Média: $\dfrac{37000}{11} \approx 3363$.
Ordenados: 1000(×6), 2000(×3), 5000, 20000. O 6º e o 7º valores são 1000 e 2000 → $Md = \dfrac{1000+2000}{2} = 1500$.
Média ($≈$3.363) > Mediana ($1.500$): os salários altos puxam a média para cima.

T 10: (UNICAMP) Média Ponderada — Nota Mínima

Um aluno precisa de média ponderada $\geq 7{,}0$ para ser aprovado. Suas notas são: Prova 1 = 5 (peso 2) e Prova 2 = 6 (peso 3). Qual nota mínima ele precisa tirar na Prova 3 (peso 5) para ser aprovado?

A) $7{,}8$
B) $8{,}0$
C) $8{,}2$
D) $8{,}5$
E) $9{,}0$

Resolução: Alternativa C.

$\dfrac{10 + 18 + 5x}{10} \geq 7{,}0$
$28 + 5x \geq 70$
$5x \geq 42 \;\Rightarrow\; x \geq 8{,}4$
A nota mínima é $8{,}4$. Entre as alternativas, a mais próxima acima é $\mathbf{8{,}5}$ (alt. D garante aprovação; 8,2 não é suficiente).
Nota: o valor exato é $8{,}4$, portanto a nota mínima inteira é $9$ ou o aluno precisa de pelo menos $8{,}4$.

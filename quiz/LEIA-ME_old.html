EXATA QUIZ

Guia de configuração · leva uns 15 minutos, uma vez só

Por que o Firebase? O GitHub Pages só guarda páginas; ele não consegue ligar o celular de cada aluno à tela do professor em tempo real. O Firebase (do Google, gratuito) faz essa ponte e também protege o seu login de professor. O plano grátis aguenta até 100 aparelhos conectados ao mesmo tempo, o suficiente para uma turma inteira.
Quer só experimentar antes? Sem configurar nada, abra professor.html numa aba e index.html em outras abas do mesmo navegador. Funciona em “modo de teste local”, com cada aba fazendo o papel de um aluno.
1

Criar o projeto no Firebase

  1. Acesse console.firebase.google.com e entre com sua conta Google.
  2. Clique em Criar um projeto (ou “Adicionar projeto”). Nome sugerido: exata-quiz.
  3. Na tela do Google Analytics, desative a opção (não precisa) e clique em Criar projeto.
2

Criar o banco de dados

  1. No menu da esquerda, abra Criação (Build) → Realtime Database.
  2. Clique em Criar banco de dados. Local: Estados Unidos (us-central1).
  3. Escolha Iniciar no modo bloqueado e clique em Ativar.

Atenção: é o Realtime Database, não o “Firestore”.

3

Colar as regras de segurança

  1. Ainda no Realtime Database, abra a aba Regras.
  2. Apague tudo o que estiver lá.
  3. Abra o arquivo regras-firebase.json (no Bloco de Notas), copie todo o conteúdo e cole no Firebase.
  4. Troque todas as ocorrências de SEU_EMAIL_AQUI pelo seu e-mail de professor (são 5 lugares). Dica: use Ctrl+H no Bloco de Notas antes de copiar.
  5. Clique em Publicar.

As regras garantem que só o seu e-mail cria quizzes e salas. Os alunos só conseguem entrar com o nome e enviar a própria resposta.

4

Ativar os logins

  1. No menu, abra Criação → Authentication → Vamos começar.
  2. Na aba Método de login, ative E-mail/senha e salve.
  3. Clique em Adicionar novo provedor, ative Anônimo e salve. (É assim que os alunos entram sem criar conta.)
  4. Na aba Usuários, clique em Adicionar usuário: digite seu e-mail (o mesmo do passo 3) e uma senha. Essa é a senha da sua área de professor.
  5. Na aba Configurações → Domínios autorizados, clique em Adicionar domínio e digite exatasite.github.io.
5

Copiar a “chave” do projeto para o arquivo config.js

  1. Clique na engrenagem ⚙ ao lado de “Visão geral do projeto” → Configurações do projeto.
  2. Em Seus apps, clique no ícone </> (Web). Apelido: exata-quiz. Não marque o Hosting. Clique em Registrar app.
  3. Vai aparecer um bloco com const firebaseConfig = { ... }. Copie os valores para o arquivo js/config.js, assim:
window.EXATA_FIREBASE = {
  apiKey: "AIzaSy...",
  authDomain: "exata-quiz.firebaseapp.com",
  databaseURL: "https://exata-quiz-default-rtdb.firebaseio.com",
  projectId: "exata-quiz",
  storageBucket: "exata-quiz.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
window.EXATA_PROFESSOR_EMAIL = "seu.email@gmail.com";

Se o databaseURL não aparecer no bloco, copie o endereço que aparece no topo da página do Realtime Database (começa com https:// e termina em firebaseio.com ou firebasedatabase.app).

Pode ficar tranquilo: essa “apiKey” é pública por natureza. Quem protege os dados são as regras do passo 3.

6

Enviar a pasta para o GitHub

  1. Abra o repositório do seu site no GitHub (o que publica exatasite.github.io/site).
  2. Clique em Add file → Upload files.
  3. Arraste a pasta quiz inteira para a janela (com o config.js já preenchido).
  4. Clique em Commit changes e espere 1 ou 2 minutos.
7

Pronto! Os endereços

  • Professor: exatasite.github.io/site/quiz/professor.html
  • Alunos: exatasite.github.io/site/quiz/ (ou pelo QR Code que aparece na tela do jogo)

Para colocar um botão no seu site, use um link para quiz/index.html. Não coloque link público para a página do professor; ela já pede senha, mas assim fica mais discreta.

O que tem em cada arquivo

index.htmlPágina dos alunos: digitam o PIN e o nome e respondem pelos naipes ♠ ♥ ♦ ♣.
professor.htmlÁrea do professor: login, pastas, editor, iniciar jogo, tela do projetor, pódio e histórico.
css/exataquiz.cssVisual do ExataSite (cores, fontes, botões).
js/config.jsO único arquivo que você edita: dados do Firebase e seu e-mail.
js/comum.jsFunções usadas pelas duas páginas (naipes, banco de dados, sons).
js/professor.jsFuncionamento da área do professor.
js/aluno.jsFuncionamento da página dos alunos.
regras-firebase.jsonRegras de segurança para colar no Firebase (passo 3).
?

Se algo não funcionar

  • “O banco recusou a operação”: confira se o e-mail nas regras (passo 3), no config.js e no usuário do Authentication é exatamente o mesmo.
  • Aluno vê “acesso de alunos não está ativado”: falta ativar o login Anônimo (passo 4).
  • Login dá erro de domínio: falta adicionar exatasite.github.io nos domínios autorizados (passo 4).
  • Mudou algo e não apareceu no site: espere 2 minutos e recarregue com Ctrl+F5.
